# Игра "Пары"

## 🎮 Правила игры
- Найди все пары одинаковых карт  
- Ограничение по времени ⏳ (таймер обратного отсчета)  

## 🛠 Технологии
### Основной стек
- **TypeScript** (статическая типизация)
- **CSS/HTML** (разметка страницы)
- **Vite** (система сборки)

### Особенности реализации
- Локальное сохранение прогресса (localStorage)
- Адаптивный интерфейс

## 🚀 Запуск

### Предварительные требования
- **Node.js** и **npm**  
  📥 [Скачать Node.js](https://nodejs.org/ru)

### Установка и запуск
1.Подготовка к запуску:
```bash
git clone https://github.com/Sahsa-123/pairs
cd pairs
npm i
npm run build
```
2.Запуск build версии с помощью vite:
```bash
npm run "preview vite"
```
3.Альтернативный запуск build версии:
```bash
npm run "preview serve"
```
